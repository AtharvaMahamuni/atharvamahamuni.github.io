MVVM

Model-View-ViewModel

Separates presentation from data using observable state holders. Ideal for modular feature screens with rapid iteration.

View (UI) ⇆ ViewModel ⇆ Repository
• Observer: StateFlow / LiveData
• Concurrency: CoroutineScope

MVI

Model-View-Intent · Unidirectional

Enforces a single immutable State and a pure reducer function. Guarantees deterministic state reproducibility and eliminates concurrency race conditions.

Intent ➔ Reducer ➔ State ➔ Render
• UDF: Single Source of Truth
• Testing: Deterministic & Replayable

Clean Architecture

Separation of Concerns & SOLID

Isolates domain business rules from external frameworks. Enables sharing a unified Android core across Panasonic's 3 distinct IFE product lines.

UI ➔ ViewModel ➔ UseCase ➔ Data
• Inversion of Control: Dagger Hilt
• 100% Unit Testable Domain Layer
